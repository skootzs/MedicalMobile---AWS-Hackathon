# Community Health Toolkit branding

Official vector source: https://docs.communityhealthtoolkit.org/icons/logo.svg

Retrieved November 4, 2026 from the Community Health Toolkit documentation website.

- `cht-logo.svg` retains the official paths, colours, lettering and gradient. Its viewport removes the source file's surrounding empty canvas for responsive display.
- `cht-mark.svg` uses the symbol paths from that same official artwork, without the wordmark, in a square viewport for the favicon.

The full logo is shared across the authenticated sidebar (including the mobile navigation drawer) and the signed-out/sign-in header. These replace the previous approximate SVG drawings and font-based wordmark.
